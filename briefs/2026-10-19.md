## TLDR

- **xAI released Grok Voice 3.0 on Oct 14, a speech-to-speech model for its Voice Agent API.** xAI reports sub-one-second latency and a first-place score of 86.9 on the Artificial Analysis Speech-to-Speech Index, against 81.3 for Grok Voice 2. The `grok-voice-latest` alias moved to 3.0 automatically, so existing agents changed models without a deploy ([Product Hunt](https://www.producthunt.com/p/spacexsi/grok-voice-3-0), [TechEnclave](https://techenclave.com/news/items/xai-releases-grok-voice-3-and-upgrades-the-latest-api-alias)).

## Where the puck is going

**Speech-to-speech is now a leaderboard race, and the index leader is the cheap one.** Grok Voice 3.0 sits at the top of the AA S2S index at a flat $0.08/min, and xAI says Starlink support runs on it at roughly 20,000 calls a day with about 70% resolved without a human. The model race is moving fast enough that cost and production proof now separate vendors more than raw quality does. The agent-task gap against GPT-Live, if it holds, suggests an index win doesn't translate into tool-use reliability.

**Silent alias upgrades are an ops risk.** Moving `latest` to 3.0 without notice means prompts, tool schemas and latency budgets tuned on 2.0 can shift overnight. Pin model versions and run regression calls on every upgrade. This is the production-hardening thread from the recovery-loop and testing-tooling themes, applied to model versioning.

**Consolidation stays the backdrop.** With Hume's API reportedly ending and big labs shipping complete stacks (voice model, builder, telephony-adjacent deployments), a founder's moat is what sits around the model: fallbacks, handoffs, vertical state and compliance. That is the same gap Vapi's GPT-Live limitations list exposed last week.
