## Where the puck is going

**ElevenLabs closing off the self-hosted MCP option is a small move that fits a pattern this brief has now tracked for months.** Every layer of the voice session — STT (Scribe becoming the enforced ElevenAgents default, Aug 20), turn control (soft-timeout controls, Aug 17), and now tool-calling (MCP) — increasingly only works the "ElevenLabs way." That's consistent with the "voice as a control surface for other agents" thread from late July: as voice agents get wired into more external tools, whoever owns the tool-integration layer owns a stickier piece of the stack than whoever owns the TTS model. Killing the self-hosted MCP option isn't a feature launch, it's a lock-in decision, and it's worth watching whether builders currently self-hosting MCP for cost or data-residency reasons push back the way some did over the forced Scribe default in June.

**Cartesia's slipping GA date is a useful data point against the leaderboard-churn thread this brief has tracked all summer.** Five different vendors have taken #1 on a TTS leaderboard since June (Alibaba, Grok/Vapi, MiniMax, Speechify, Cartesia), and the assumption built into that thread has been that "#1 on Artificial Analysis" converts into a shipped default fairly quickly. Cartesia is the first case this brief has watched closely enough to see that gap open in real time: docs still default to 3.5, no GA date nine days after the beta, and a self-declared deadline about to pass. Worth remembering the next time a vendor announces a leaderboard win — "#1" and "what's running in production" are still two different dates, and sometimes by weeks, not days.

**The Deepgram changelog activity is more of the same "maintenance tier is where the real work is happening" pattern flagged Aug 10** — nothing headline-worthy, but CLI parity for a model that GA'd two weeks ago and steady language coverage expansion are exactly the unglamorous work that determines whether a launch is actually usable, versus just announced.
