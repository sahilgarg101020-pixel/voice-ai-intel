## TLDR

- **Retell launched Retell Dialer, an outbound campaign engine (Nov 18).** It calls and texts each contact at a scheduled time, follows up based on rules, and writes every outcome back to the CRM. Campaigns can use a fixed list or auto-enroll new leads that match rules. DNC lists, reassigned-number checks and calling hours are toggles on each campaign. Batch Calls is deprecated in favor of Dialer. One catch: "Verify first, launch in 7 days" is on by default and pushes back even a "Launch now" start ([Retell changelog](https://www.retellai.com/changelog/retell-dialer), [docs](https://docs.retellai.com/dialer/overview)).
- **Berlin-based Elbic raised a €2.7M pre-seed for localized, sovereign voice models for European companies (Nov 25).** London's Repeat Ventures led the round. That puts at least five funded EU-sovereign speech startups on the tracker: Reson8, Deepslate, SLNG, Neuphonic and Elbic ([N24](https://n24.com.tr/en/technology/elbic-raises-27-million-euros-for-sovereign-voice-ai-576), [ByteBrief](https://bytebrief.ai/article/50af65929cbce94370ee8880908584c2ed8c75739cc0979f8fae7103ca74a5ab)).
- **Deepgram added Odia, Santali, Southern Ndebele and Western Frisian to Nova-3 and updated models for other languages (Nov 24).** This is per a release-notes aggregator; I couldn't confirm it in Deepgram's own changelog ([Releasebot](https://releasebot.io/updates/deepgram)).
- **An operator running about 5,000 calls a month says a human-sounding voice no longer differentiates.** They screen call-center candidates by phone and say the value is the structured record that lands in the CRM after each call. They add that nobody replays the recordings (Reddit, Nov 25, via [KBlip](https://kblip.com/social/stop-demoing-how-human-your-voice-agent-sounds-nobody-using-XPSDpeA) / [AGI Hunt](https://agihunt.info/en/p/1a21132a835efba5bebd1d8c8ba)).

## Where the puck is going

**The product is the call outcome, not the conversation.** Retell Dialer and the operator's post point the same way. Retell is turning the agent platform into a campaign system: scheduling, retry rules, compliance checks and writing results to the CRM. It joins Convoso's dialer-native agent and Aircall's outbound campaigns. The operator says the same thing from the buyer's side: ops teams consume the CRM row, not the recording. For builders, the output schema (fields extracted, how confident the agent was, what follow-up is due) is now a core part of the product. The voice model matters less to the buyer. This strengthens the tracker theme that value is moving to actions, state and recovery.

**Compliance is becoming a set of default product settings.** Two days after the FCC's TCPA revocation rules took effect, Retell ships DNC, reassigned-number and calling-hour checks as toggles. It also turns on a 7-day verification wait by default. Expect every outbound platform to compete on how much of the TCPA burden it takes on. If you sell outbound, being able to show what checks ran on each dial will soon be a basic requirement.

**Sovereign speech in Europe is getting crowded.** Elbic adds another sub-€10M EU speech startup. Gladia was already bought by OVH, so there is now a path to acquisition by European cloud providers. Data residency alone won't set these startups apart much longer. The winners will need hard accuracy in a specific language or domain, or an EU cloud distribution deal.

## Signals from the field

- **Operator take:** "Nobody replays call recordings." Build for the CRM row, not for how the call sounds ([KBlip](https://kblip.com/social/stop-demoing-how-human-your-voice-agent-sounds-nobody-using-XPSDpeA)).
- **Practitioner bar:** a 2026 barge-in guide sets production targets of a 200–400ms turn gap, under 2% false barge-ins and under 60ms TTS flush ([FutureAGI](https://futureagi.com/blog/voice-ai-barge-in-turn-taking-2026/)). This continues the turn-taking theme. A vendor wrote these numbers, but they make a useful acceptance test.
