## TLDR

- **Gartner says reasoning speech models move voice from routing calls to resolving them.** It projects that more than 70% of enterprise voice interactions will be handled autonomously by 2030, up from under 10% in 2026, and that these models can resolve 30–80% of inbound volume. Its advice is to sort calls by complexity: simple calls go to fast, low-latency models and hard calls go to deeper reasoning models. Gartner also named speech reasoning models a Top Strategic Technology Trend for 2027 ([Gartner](https://www.gartner.com/en/articles/speech-reasoning-models-voice-resolution), [Gartner abstract](https://www.gartner.com/en/documents/8387081)).
- **Vapi Agent Loop (early access since Nov 11, GA planned for early 2027) improves an agent automatically.** It watches live calls, scores them against a business goal, proposes changes to the model, voice, settings and tools, tests those changes in simulation, then sends a share of live traffic to the improved version and rolls back changes that lose. Coverage says a human must approve changes before they ship ([Vapi](https://vapi.ai/blog/agent-loop-launch), [RuntimeWire](https://runtimewire.com/article/vapi-agent-loop-voice-agents-early-access)).
- **Boson AI previewed Higgs Realtime Duplex (Nov 5).** It is a 45B full-duplex model that hears, sees and speaks at the same time and renders a face. It works in 160ms chunks and calls tools itself, only handing harder turns to a backend. On Boson's own runs it scores 98.9 on Big Bench Audio but trails on Full-Duplex-Bench v1.5: 75.5, against 77.8 for Thinking Machines and 80.1 for GPT-Live-1. There is no API yet, only a waitlist, and no published price ([audioXpress](https://audioxpress.com/news/boson-ai-previews-higgs-realtime-duplex-for-conversational-voice-and-video-agents), [RuntimeWire](https://runtimewire.com/article/boson-higgs-realtime-duplex-45b-voice-face-model)).
- **Minor:** Trigent launched Calypso (Nov 24), a managed service that puts a live voice agent on real calls in under 24 hours and includes an ROI assessment before full rollout. The only source is the press release ([MENAFN](https://menafn.com/1112014811/Trigent-Launches-Calypso-To-Help-Companies-Test-AI-Voice-Agents-On-Live-Calls-Before-Rollout)).

## Where the puck is going

**Agents that improve themselves from live calls are becoming a platform feature.** Coval and Phonely's retrain-on-real-calls loop (September) was a partnership. Vapi has now built the loop (observe, propose, simulate, split traffic, roll back) into the core platform, and Retell's Conductor and Cekura are close behind. Two things follow for builders:

- A standalone "voice evals" product now competes with a feature the platforms give away.
- What remains defensible is the business-outcome signal the loop optimizes against, such as a booked appointment, a payment or a cancellation avoided. Most teams still don't feed that signal back from their CRM.

If you sell on top of Vapi or Retell, expose a clean outcome event the loop can read.

**Gartner's routing advice is the same architecture builders are already using.** Fast models handle easy turns and reasoning models take the hard ones. It matches Boson letting the duplex model answer and only calling the backend when needed, and the "voice is a thin front-end, value is in actions and state" theme in the tracker. The useful part is the analyst framing: enterprise buyers will start asking which tier handles each call type and what each tier costs. Have a per-intent cost-and-latency table ready.

**Full-duplex keeps advancing as previews while turn-based agents earn the money.** Boson, Block's Dessa (Oct 23, waitlist) and Thinking Machines all show listen-while-speaking models, but none is generally available with a price. Production phone agents still run on turn-based models with good end-of-turn detection. Until a duplex model posts results on 8kHz phone audio and has a price, treat duplex as a 2027 roadmap item, not a reason to rebuild.

## Signals from the field

- **Reliability:** ElevenLabs logged a latency and API error incident that affected agent conversations on Nov 18, recurred, and was fixed Nov 19. It is one more reason to configure STT/TTS failover; Twilio made STT failover GA last cycle ([IsDown](https://isdown.app/status/elevenlabs/incidents/689842-increased-latency-and-api-errors)).
- **Developer field note:** a post on agents cutting themselves off on real phone lines, a problem browser demos hide: "an agent that felt great in testing starts 'randomly' cutting itself off once it has a real number." The cause is echo of the agent's own voice, not turn detection ([DEV](https://dev.to/piyuzz/stop-your-voice-agent-interrupting-itself-on-phone-calls-soniox-stt-v6-agent-text-paced-from-the-162f)).
- **Benchmark caveat:** Boson's duplex scores are its own runs, and one outlet reports an IFEval figure no other source repeats.
