## TLDR

- **Twilio is hardening Conversation Relay for production.** Smart Turn Detection is GA as of Nov 13. It is a Twilio-built semantic end-of-turn model that runs in Twilio's media stack, works with every supported STT provider except Deepgram Flux, and is toggled per call. It also emits start-of-turn, eager-end and end-of-turn events over WebSocket. Automated STT failover is also GA. Agent Connect bridges agent stacks from AWS, Google, Azure and OpenAI. One caveat: Twilio's docs say turn detection is **not PCI compliant or HIPAA-eligible** ([Twilio changelog](https://www.twilio.com/en-us/changelog/general-availability--smart-turn-detection-for-conversationrelay), [turn detection docs](https://www.twilio.com/docs/voice/conversationrelay/turn-detection), [CMSWire](https://www.cmswire.com/contact-center/twilio-expands-voice-ai-stack-with-8-new-features/)).
- **Microsoft Teams now certifies voice agents.** Under the Teams Voice Agent Certification Program's "Unify" integration model, AudioCodes and AnywhereNow are already certified. NiCE Cognigy said on Nov 18 it is among the first to complete certification, and roughly seven more contact-center vendors are reportedly in process ([Microsoft Learn](https://learn.microsoft.com/en-us/microsoftteams/teams-voice-agents), [Speech Tech](https://www.speechtechmag.com/Articles/News/Speech-Technology-News/AudioCodes-AnywhereNow-Certified-by-Microsoft-176180.aspx)).
- **Zyphra released ZONOS3-Mini as open weights under Apache 2.0.** It is a sparse mixture-of-experts text-to-speech model with 100M active and 800M total parameters, covering 43 languages with zero-shot voice cloning. It runs in the browser and on device. Zyphra reports 80ms time-to-first-audio on an H100. Outlets report on-device numbers inconsistently: either about 150ms on an M3 Air and about 570ms in a Pixel 9 browser, or under 450ms and under 800ms ([AI Weekly](https://aiweekly.co/alerts/zyphra-open-sources-zonos3-mini-moe-tts-at-80ms-first-audio), [AlphaSignal](https://alphasignal.ai/news/zyphra-s-zonos3-mini-clones-voices-in-43-languages-directly-on-your-phone)).
- **Reson8 posted Rumble-2-Flash, a 0.5B-parameter speech recognition model, to Hugging Face (Nov 18).** It ships with Transformers and vLLM support. Coverage calls it Apache 2.0, but Artificial Analysis lists Reson8 as proprietary and the model card looks partly copied from another model, so check the license before you build on it ([HF](https://huggingface.co/Reson8/Rumble-2-Flash)).
- **Minor:** ChatGPT reportedly got streaming "Live Dictation" on Nov 18, which removes the 10-minute recording cap on all plans. This comes from secondary coverage only ([tbreak](https://tbreak.com/chatgpt-live-dictation/)).

## Where the puck is going

**Turn detection is turning into a free platform feature.** Pipecat unbundled it into classifiers. LiveKit published interrupt-rate data, and Deepgram builds it into Flux. Now Twilio ships a semantic turn model inside the carrier media path with eager-end events. If your differentiation is "we built a better endpointer," the telephony layer is giving that away for free. What still has value is what sits on top of the turn signal: acting on *eager* end-of-turn (speculative LLM and tool calls that get cancelled if the user keeps talking) and recovering cleanly after barge-in. Note the compliance gap, too: healthcare and payments callers can't use Twilio's turn model today. A vertical stack that offers HIPAA-eligible turn-taking has a real wedge for the next few months.

**The incumbents' platforms are adding certification gates.** Last cycle, ElevenLabs and Deepgram opened marketplaces. This cycle, Microsoft added a certification program for voice agents in Teams. The new NiCE Cognigy, released Nov 12 with native speech-to-speech, arrives already certified. Dialpad's merger with Ada (Nov 4) also pairs a voice network with an agent company. Enterprise voice agents are being sold through UCaaS and CCaaS channels that now have formal quality bars. A startup selling into Teams-heavy enterprises should treat certification as a sales prerequisite, and the incumbents are getting there first.

**Open TTS small enough to run on device keeps getting better.** ZONOS3-Mini at 100M active parameters, Kugel/Miso-class models, and Google's ML Kit on-device ASR/TTS from three days ago all point the same way. Cloning and multilingual voices at the edge are becoming free to obtain. The tracker's TTS price-war theme now has a floor of zero for anyone willing to self-host. Paid TTS has to win on expressiveness under load and on consistency across long calls, not on access.

## Signals from the field

- **Spec detail worth noting:** Twilio's failover only fires if an action URL is set on `<Connect>`, and its own guide says "always set ttsProvider and transcriptionProvider" even when using the defaults. Failover that is GA is not automatic until you configure it ([Twilio](https://www.twilio.com/en-us/blog/developers/best-practices/conversation-relay-failover)).

It is a fair reminder for every front-desk agent pitch ([UCStrategies](https://ucstrategies.com/news/newo-raises-25m-to-replace-human-receptionists-but-one-ai-mistake-could-cost-thousands/)).
