## Where the puck is going

Offline voice is a regulated-buyer story. Defense, government and healthcare buyers can't send audio to a cloud API, and the cloud-first stack (Vapi, Retell, hosted TTS) has little to offer them. Deepgram is going after that gap from the STT side, and laptop-class hardware is the first target where the economics could work. The open questions are model size and whether a TTS and agent layer follows the STT. If it doesn't, the offline pitch covers transcription only, not agents.

This lines up with the price-war thread. As raw API access keeps getting cheaper, vendors are moving toward deployment constraints (air-gapped, on-prem, sovereign) where price is not the main buying criterion. If you build for regulated verticals, compliance and where the model runs are becoming product features, not just procurement paperwork.

News flow is thin because the post-DevDay and Microsoft release wave has settled. The next movers are likely independent benchmarks for the Microsoft models, ElevenLabs' v4 pricing reception, and more platform M&A.
